## Context
A nested git worktree under .claude/worktrees/ (branch fix/default-filter-hides-expired) contains stale duplicate specs. vitest.config.ts (excludes e2e, node_modules) and eslint.config.mjs (ignores .next/coverage/__mocks__) do not exclude .claude/**, so the default `npm test` and `npm run lint` pick up the worktree copies: ~6 test failures and 2 lint errors, all on .claude worktree paths. Workaround used during mcp-write-tools implementation: scope runs to `npx vitest run --dir __tests__`.

## Decision Deferred
Whether to add .claude/** to the vitest and eslint ignore globs so the default suites are clean regardless of nested worktrees.
